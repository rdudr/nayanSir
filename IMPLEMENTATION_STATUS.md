## 🚀 Getting Started (3 Steps)

### Step 1: Install Dependencies
```bash
npm install
```
**Time**: ~2-3 minutes  
**What it does**: Downloads React, Next.js, Framer Motion, Tailwind, etc.

### Step 2: Start Development Server
```bash
npm run dev
```
**Time**: ~10-15 seconds  
**What it does**: Starts local server on http://localhost:3000

### Step 3: View Your Site
Open browser: **http://localhost:3000**  
**Result**: Beautiful research portfolio with all sections!
